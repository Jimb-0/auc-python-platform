# Lesson: Variables

## 1. Explain

A variable is a labeled box that holds information. You give it a name, then use `=` to put something inside.

```python
name = "Jim"
```

The box is called `name`, and it holds the text `"Jim"`.

## 2. Predict

What do you think this prints?

```python
name = "Jim"
print(name)
```

a) `name`
b) `Jim`
c) an error

<details>
<summary>Show answer</summary>

**b) `Jim`** — `print` shows what's *inside* the box, not the box's label.

</details>
